#DronWO: Towards Drones as Writable Surfaces

## 🛩️ Human-Drone Interaction with Crazyflie 2.1

This project explores a novel **Human-Drone Interaction paradigm** developed as part of my thesis at **Politecnico di Milano** in collaboration with the **[NESLab](https://www.neslab.it/)**, under the supervision of **Prof. Luca Mottola**.

💡 The goal: allow **non expert end-users to dynamically customize drone behavior at runtime**, without needing to reprogram the system.

🛠️ Built on **Crazyflie 2.1 nanodrones**, the solution was fully **prototyped and tested with 10 volunteer users**, validating its usability and flexibility.

🎥 [See the demo and more info](https://tinyurl.com/dronWOresults)

---

📁 This repository includes:
- Source code for the interaction logic and behavior configuration
- Test scenarios and user interface components
- Scripts and setup instructions for running on Crazyflie 2.1
